Checklist for Projects and Tasks

Most teams track sub-steps in comment threads, spreadsheets, or their own memory - and things slip through. This module puts real, reusable checklists directly on Odoo tasks and projects, so every step has a status, an owner category, and a place to live.

Build checklist templates once per category (Bug Fix, Feature Request, Client Onboarding - whatever fits your process), attach one or several to any task or project, and let each item move through To Do, In Progress, Done, or Cancelled. A live progress bar reflects reality on the task, project, and Kanban card - and you can require a checklist to be fully complete before a task is allowed into a given stage.

Build a Checklist Once, Reuse It Everywhere

Create a checklist template with as many items as the job needs, organise it under a category, and reuse it across every matching task or project - no retyping the same steps twice.

Attach More Than One Checklist When One Isn't Enough

Complex tasks rarely fit a single checklist. Select multiple checklists from the same category on one task or project, and track every one of them side by side.

Move Every Item Through a Real Workflow

Mark items To Do, In Progress, Done, or Cancelled with one click, add new lines on the fly, and remove items or whole checklists the moment they stop being relevant.

A Progress Bar That's Always Telling the Truth

Every completed or cancelled item recalculates the progress bar instantly across form, tree, and Kanban views - so status meetings start with facts, not guesses.

Organise Checklists the Way Your Process Actually Works

Group checklists into categories like Bug Fix, Feature Request, or Client Onboarding, so the right template is always easy to find and apply.

Keep Specialised Checklists With the People Who Should Run Them

Link a user group to any checklist category and only that group can create, edit, or advance items in it - sensitive processes stay contained to the right team.

FAQs

Smart Task Management in Odoo - Auto Numbering, Quick Search & Automate

Q1. Why choose this Checklist app over just adding sub-tasks?

Sub-tasks create separate records to manage; this app keeps a lightweight, reusable checklist directly on the task or project record itself, with its own 4-state workflow, a live progress bar, and category-based access control - all without cluttering your project structure with extra task records.

Q2. How do I create and apply checklists?

We've put together a full step-by-step guide covering every feature: https://web.kopyst.com/sharedoc/b73d307f51. If you need a hand with anything specific, email odoo-support@zehntech.com and we'll help directly.

Q3. I need some customization in this app. Is it possible?

Yes, we can customize this module to meet your requirements. This app supports Odoo environments such as Odoo.sh and Odoo Community/self-hosted installations, subject to technical feasibility. If you require customization, please contact us at odoo-support@zehntech.com

Q4. How can I search for tasks using the reference number?

You can use the custom global search box to search tasks using the full or partial reference number, including prefix/suffix.
